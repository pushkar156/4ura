# Aura Menu QR App

A modern, responsive website for Aura's QR-based menu system. This frontend implementation allows customers to scan a QR code to access the restaurant's menu.

## Features

- Clean, modern design
- Responsive layout
- QR code display
- Smooth navigation
- Mobile-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Google Fonts (Inter)

## Getting Started

1. Clone this repository
2. Open `index.html` in your web browser
3. No additional setup required as this is a frontend-only implementation

## Project Structure

- `index.html` - Main HTML file
- `styles.css` - Stylesheet
- `script.js` - JavaScript functionality
- `README.md` - Project documentation

## Note

This is a frontend-only implementation. The QR code currently points to a placeholder URL. To make it functional, you would need to:

1. Set up a backend server
2. Create a menu system
3. Update the QR code URL to point to your actual menu page
